## Overview

WiFi Share (واي فاي شير) is an Android utility designed for effortless, ultra-fast local file and folder transfers over Wi-Fi Hotspot, featuring simultaneous send/receive, transfer resumption, and one-time device pairing. The interface is strictly right-to-left (`dir="rtl"`) in Arabic, using a luxury dark-mode aesthetic anchored by deep obsidian-emerald surfaces that eliminate harsh glare and reduce eye strain. Every screen prioritizes clarity, speed, and zero-friction pairing through generous negative space, crisp typographic hierarchy, and single-tap primary actions.

## Layout & Spacing

The layout uses a single-column **Fluid Grid** on mobile (`390px` Android viewport) with `16px` horizontal page margins and a strict `4px` / `8px` spacing scale. Primary actions (Send and Receive) sit in an ergonomic thumb-friendly zone, while active transfers and paired devices stack cleanly with generous vertical rhythm.

```yaml
spacing:
  gutter-xs: 4px
  gutter-sm: 8px
  gutter-md: 12px
  gutter-lg: 16px
  gutter-xl: 24px
  section: 32px
  page-margin: 16px
```

## Elevation & Depth

Depth is achieved through **tonal layering** rather than heavy drop shadows. The base canvas sits at `surface` (`#0E1511`), primary cards step up to `surface-container` (`#1A211D`), and interactive controls or nested tiles step up to `surface-container-high` (`#242C27`). Subtle `1px` ghost borders using `outline-variant` (`#3C4A42`) separate adjacent cards cleanly without visual noise.

## Shapes

Generous, modern Android Material-inspired radii give the dark emerald surfaces a refined, tactile feel. Primary action cards and modal sheets use `xl` (`24px`) corners, standard cards use `lg` (`16px`), buttons and chips use `md` (`12px`) or `full` (`9999px`) for pill controls.

```yaml
rounded:
  sm: 6px
  DEFAULT: 12px
  md: 12px
  lg: 16px
  xl: 24px
  full: 9999px
```

## Motion & Micro-interaction

Motion is crisp, responsive, and purposeful. Tap feedback and state transitions resolve in `120ms`, while bottom sheets and pairing overlays enter with a smooth `240ms` decelerating curve. Nothing loops decoratively; only active hotspot discovery or live transfer progress indicators animate subtly.

```yaml
motion:
  state-change:
    duration: 120ms
    delay: 0ms
    timingFunction: ease-out
  surface-enter:
    duration: 240ms
    delay: 0ms
    timingFunction: cubic-bezier(0.2, 0, 0, 1)
  surface-exit:
    duration: 160ms
    delay: 0ms
    timingFunction: cubic-bezier(0.3, 0, 1, 1)
```

## Voice & Content Strategy

All copy is written in clear, modern Arabic (`dir="rtl"`) with a calm, direct, and reassuring tone. Actions use concise verb phrases that state the outcome directly (e.g., "إرسال ملفات", "استقبال الآن", "استكمال الإرسال", "مسح QR للربط"). Technical jargon is avoided in favor of plain status indicators ("متصل لمرة واحدة", "نقطة الاتصال نشطة", "جاهز للاستقبال"). Numbers, transfer speeds, and file sizes use Western Arabic numerals (`0-9`) in `JetBrains Mono` for instant scannability.
